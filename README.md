**Neon Coast Cover Studio** — an offline web app that turns your photo and a caption into multi-panel GTA-style poster cover art: pick a layout, a sunset or neon grade, write the title, and export a PNG in 1080×1080, 1080×1350 or 1920×1080. Photos never leave your machine; no uploads, no accounts, no watermarks.

- 6 layouts (Hero + Three, Four Grid, Full Bleed, Nine Grid, Tilted Snapshots, Story Stack)
- 6 colour grades (Sunset Vice, Neon Nights, Golden Hour, Teal Dusk, Mono Noir, Palm Pop)
- Per-panel crop: click a panel, drag to pan, scroll to zoom; one photo or several
- Bold Anton title with a sunset gradient, Pacifico neon subtitle, tag line + heat-meter stars
- Film grain, vignette and halftone finish; undo/redo; export all three post sizes at once

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests. Node 22+ is all it takes.
